# KAMA STŘECHY

Web pokrývačské a klempířské firmy Jiřího Švece z Hlinska. Moderní dark design v barvách černá, bílá a oranžová.

## Stack

- HTML / CSS / JavaScript
- PHP (kontaktní formulář)
- Google Fonts — Bebas Neue + DM Sans

## Struktura

```
index.html        — celý web
css/style.css     — styly
js/main.js        — interakce
php/contact.php   — odesílání formuláře
images/           — logo, galerie, partneři
```
